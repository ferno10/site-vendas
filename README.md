markdown# 🛒 Site Básico de Vendas (Vitrine)

Este é um projeto de uma vitrine virtual simples desenvolvido para praticar conceitos de HTML5 e CSS3.

## 🚀 Tecnologias Utilizadas
- HTML5 (Estruturação)
- CSS3 (Estilização e Flexbox)

## 🛠️ Como rodar o projeto
1. Faça o clone do repositório.
2. Abra o arquivo `index.html` em qualquer navegador.
